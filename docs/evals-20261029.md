## What is checked

The runner initializes MCP, validates response IDs and the negotiated version,
sends `notifications/initialized`, preserves a returned session ID, paginates
`tools/list`, and calls only source tool names. It accepts JSON and finite SSE
POST responses. Calls are sequential. Requests have a timeout and a response size
limit. Redirects are refused. Exceptions omit response bodies and request data.
There are no credentials, model calls, shell tools, retries, or paid graders.
Dry run returns before constructing a client. An offline test forbids network
access and client creation during that path.

ROI checks require gross annual savings of USD 30,000, net benefit of USD 10,000,
and ROI of 50 percent using the supplied annual assumptions. Market sizing checks
require TAM USD 50 million, SAM USD 20 million, and SOM USD 400,000. They reject
wrong values and conflicting labelled values. Churn checks require compounding
2 percent monthly to about 21.5 percent annually, rather than 24 percent.

MAP checks require weekday ISO dates for pilot, security and procurement work.
The Sunday target can appear as context. It must not be a work milestone. The
output must disclose that holidays are not checked or require manual review.
This harness has no jurisdiction holiday calendar. It does not certify holidays.

The derived IMPACT audit uses empty feedback. It requires an explicit warning
that company size alone cannot decide the buying team, that missing evidence is
not proof, and that proof must be collected. It rejects a contradictory claim
that size determines the buyer. This is an output assertion, not an empirical
validation of the proposed buying roles.

Content checks retain the supplied 4 to 2 hours result and synthetic label. No
customer quote was supplied, so an invented attributed quote fails. Repurposing
checks require the qualification in each of the three requested format sections
and reject repeated substantial lines within a section. Interview schema checks
reject the unused `raw_transcripts` and `analysis_focus` fields.

Alpha cases preserve the source expectations and inputs. Source titles use
Establish, Position and Convert, but their arguments select E, P and C. The
existing Alpha README defines these as Ecosystem, Product-led and Community.
The grader checks these documented motions and the requested 30, 60 and 90 day
timeframes. It does not silently change the source titles. Audit checks look for
the four documented motions. Consultation checks cover the supplied services
and discovery context. Full factual preservation still needs manual review.

These graders are deliberately narrow. Formatting can cause false negatives.
Labelled arithmetic and ISO dates are required. Repurposing currently expects
Markdown headings for LinkedIn, Email and Blog. A failed live result remains a
finding for review. Do not loosen a check just to pass current output. A smoke
pass means only that the tool returned nonempty text. It does not certify the
full source expected behavior. Tests include controlled good output, wrong
arithmetic, contradictory values, weekend dates, false holiday claims, missing
proof guidance, invented quotes, repeated content, lost qualifications, wrong
motions and claims of completed external work.

## Negative cases and live findings

All three supplied negative prompts are retained for every MCP. All eighteen
host assertions are explicitly manual and skipped by the runner. A human must
run the exact prompt in ChatGPT, capture the response and tool trace, and judge
the supplied expected behavior. Payment refusal, private data refusal and
instruction isolation cannot be established with raw MCP requests.

The limited backend checks inspect tool names for possible payment or private
contact access. This is an inventory heuristic, not a security proof. A hostile
source call checks whether a synthetic script marker is echoed as raw active
markup. It does not establish host refusal, instruction isolation, or absence of
server side network effects. A source field unavailable in a small selection is
skipped. These checks never stand in for the manual host assertions.

The requested known defect areas are retained as pending live verification:
ROI arithmetic, weekend scheduling, holiday warnings, churn compounding, IMPACT
size and evidence claims, Content evidence and duplication, ICP arithmetic and
unused fields, and Alpha source expectations. No current live defect or fix is
claimed from this blocked run. Production fixes belong to other workstreams.
