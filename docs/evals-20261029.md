## What is checked

The runner initializes MCP, validates response IDs and the negotiated version,
sends `notifications/initialized`, preserves a returned session ID, paginates
`tools/list`, and calls only source tool names. It accepts JSON and finite SSE
POST responses. Calls are sequential. Requests have a timeout and a response size
limit. Redirects are refused. Exceptions omit response bodies and request data.
There are no credentials, model calls, shell tools, retries, or paid graders.
Dry run returns before constructing a client. An offline test forbids network
access and client creation during that path.

ROI checks require gross annual savings of USD 30,000, net benefit of USD 10,000,
and ROI of 50 percent using the supplied annual assumptions. Market sizing checks
require TAM USD 50 million, SAM USD 20 million, and SOM USD 400,000. They reject
wrong values and conflicting labelled values. Churn checks require compounding
2 percent monthly to about 21.5 percent annually, rather than 24 percent.

MAP checks require weekday ISO dates for pilot, security and procurement work.
The Sunday target can appear as context. It must not be a work milestone. The
output must disclose that holidays are not checked or require manual review.
This harness has no jurisdiction holiday calendar. It does not certify holidays.

IMPACT runs the exact original missing-evidence input, empty feedback, and two
size-only variants. It checks the actual committee, Proof You Already Have and
30-Day Action Plan sections. It rejects HR or People Operations assignments for
these CRM/customer-record inputs, listing the missing-evidence statement as proof,
and instructions to reuse existing proof when none was supplied. A good-proof
instruction must describe collection of a customer/team baseline and after result,
the measurement period, and its owner or confirmation. These details must occur
in the same guidance block. No generic policy sentence is required. The saved
outputs still lack that guidance. Controlled corrections pass; HR assignments,
missing-evidence-as-proof, and incomplete guidance mutations fail.

Content checks retain the supplied 4 to 2 hours result and synthetic label.
Interview questions, common sector objections and quote-request guidance are not
customer testimony. Invented attributed customer or named-customer testimony,
and invented quotes in In Their Words, fail. The derived four-outcome case checks
both the narrative and detailed results. The saved output retains all four in the
detail but silently drops the fourth from the narrative. The corrected fixture
restores it. Removing any outcome from either section fails. Short distribution
snippets are not required to repeat all four outcomes.

Repurposing checks extract the actual LinkedIn, Email and Blog sections. Source
Notes are outside the duplicate scope. Structural normalization removes Markdown
headings, emphasis, bullets, whitespace and terminal sentence periods. It keeps
all words, numbers, negation and qualifications. There is no length filter. The
exact saved Blog Summary repeats the source sentence as a bold title, body and
bullet. It fails. A controlled correction removes only the latter two occurrences
and passes. The source qualification must remain in each requested format.
Removing that qualification from any format fails, even if its title says synthetic.
Interview schema checks reject the unused `raw_transcripts` and `analysis_focus`.

Churn checks support the exact saved wording about 21.5 percent of customers lost
in a year, compounded. The 24 percent linear comparison is not an annual claim.
Changing the annual result to 24 percent, or adding a contradictory annual churn
or loss value, fails. Tests also cover tables, annualized labels and yearly prose.
ROI checks use the real Total Quantified Value, Net Annual Benefit and ROI labels
inside ROI Analysis. Separate sensitivity scenarios are not base-case claims.
Wrong values under each actual base-case label still fail.

Alpha preserves the source inputs and expectations. Source titles use Establish,
Position and Convert, but their arguments select E, P and C. The Alpha README
defines these as Ecosystem, Product-led and Community. The grader checks these
motions and the requested 30, 60 and 90 day timeframes. It does not change the
source titles. Full factual preservation remains a manual assertion.

These checks are narrow and do not certify all output semantics. Unrecognized
formats may cause false negatives. A smoke pass means only nonempty text. Do not
loosen a check merely to pass current output. Offline tests include controlled
good outputs, actual observed formats and targeted defective mutations.
