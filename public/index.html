ICP Intelligence

Ideal customer profile tools for B2B go-to-market teams

Setup and toolsQuestionsPrivacySource codeAll connectors

ICP Intelligence gives Claude nine tools for defining and using an ideal customer profile: a deep dive on your best customers, a scoring model, buyer group mapping, a TAM, SAM and SOM calculation, lookalike targeting criteria, account prioritization, gap analysis, ICP change tracking and interview synthesis. Every tool works only from the data you give it; it does not look anything up.

Connect

Server URL

https://icp-intelligence.gtmhelix.com/mcp

Transport: Streamable HTTP (stateless, JSON responses). Authentication: none. Send MCP JSON-RPC messages with POST; other methods return 405, which is expected.

Claude (web, desktop and mobile)

  1. Open Customize, then Connectors, then Add custom connector.
  2. Name: ICP Intelligence. MCP server URL: https://icp-intelligence.gtmhelix.com/mcp.
  3. Choose no sign-in, then Add. Turn the connector on for a chat with the + menu.

Claude Code

claude mcp add --transport http icp-intelligence https://icp-intelligence.gtmhelix.com/mcp

Run it locally instead (npm, stdio)

npx -y @shashwatgtmalpha/icp-intelligence-mcp

The npm package and this hosted server run the same code.

Questions and answers

What is ICP Intelligence?

ICP Intelligence gives Claude nine tools for defining and using an ideal customer profile: a deep dive on your best customers, a scoring model, buyer group mapping, a TAM, SAM and SOM calculation, lookalike targeting criteria, account prioritization, gap analysis, ICP change tracking and interview synthesis. Every tool works only from the data you give it; it does not look anything up.

How do I connect ICP Intelligence to Claude?

In Claude, open Customize, then Connectors, then Add custom connector. Name it ICP Intelligence, paste the server URL https://icp-intelligence.gtmhelix.com/mcp, choose no sign-in and select Add. In Claude Code run: claude mcp add --transport http icp-intelligence https://icp-intelligence.gtmhelix.com/mcp

Does ICP Intelligence need an account, and what does it cost?

No account or sign-in is needed, and there is no charge. The server is public and every tool is read-only.

Which tools does ICP Intelligence include?

9 tools: ICP Deep Dive, ICP Scoring Model, Buyer Group Analyzer, TAM SAM SOM Calculator, Lookalike Signal Generator, Account Prioritization, ICP Gap Analysis, ICP Evolution Tracker, ICP Interview Synthesizer.

What data does ICP Intelligence keep?

None. Each call is answered from the inputs you give it, and the server stores and logs nothing. Netlify, the host, keeps its own request logs. See the privacy policy.

Can I run ICP Intelligence on my own computer?

Yes. Run npx -y @shashwatgtmalpha/icp-intelligence-mcp to use the same tools locally over stdio; nothing is sent to us.

Who built ICP Intelligence?

Troubleshooting

  • 405 Method not allowed: you opened the server URL in a browser or sent a GET. Use an MCP client, which sends POST.
  • 429 Too many requests: the server allows 300 requests per minute from one address. Wait a minute and try again.
  • "Missing required input": the tool was called without one of the required inputs listed above.
