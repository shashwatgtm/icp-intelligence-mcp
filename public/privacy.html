Who we are

ICP Intelligence is built and run by Shashwat Ghosh, Helix GTM Consulting. Contact: shashwat@gtmhelix.com.

What this server receives

When an AI assistant such as Claude calls one of the tools, this server receives the tool name and the inputs for that call (for example a product description or a list of competitors). It does not receive your chat history, your account details, your files or anything else from your conversation.

How it is used and stored

  • The inputs are used only to build the text that the tool returns, inside that one request.
  • The server keeps nothing: there is no database, no file storage and no cache. Each request starts from nothing and ends when the reply is sent.
  • Our code does not log tool inputs or outputs.
  • There are no accounts, no cookies, no analytics and no advertising.

Who else processes data

  • Netlify hosts this server and these pages. Like any web host, Netlify processes each request (including your IP address) to deliver it and keeps its own platform logs under its own policy: netlify.com/privacy.
  • Google Fonts: these web pages (not the MCP server) load fonts from Google, which receives your IP address: policies.google.com/privacy.
  • Your AI assistant's provider (for example Anthropic for Claude) handles your conversation under its own policy.

We do not sell or share data with anyone else.

Retention

We keep no tool inputs or outputs, so there is nothing for us to delete. Netlify's platform logs are kept by Netlify under its policy.

Local version

The npm package (@shashwatgtmalpha/icp-intelligence-mcp) runs entirely on your own computer and sends nothing to us.

Changes

We will update this page if the server's handling of data changes. The date at the top shows the latest version. Questions: shashwat@gtmhelix.com.
