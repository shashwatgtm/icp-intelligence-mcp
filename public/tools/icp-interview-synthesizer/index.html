Who is ICP Interview Synthesizer not ideal for?

  • Teams looking for a list of companies to target: the tools describe and score profiles from your data but find no companies.
  • Market sizing without your own numbers: TAM, SAM and SOM are built from the figures you enter; an ICP match rate or market share you leave out is filled with a labelled example (30% and 3%).

How do I use ICP Interview Synthesizer from Claude?

Add ICP Intelligence once (see Use it in Claude or ChatGPT), then ask in plain words. A prompt built from the tested example:

Use ICP Intelligence's ICP Interview Synthesizer tool. interview notes: Clinic Group A (role Operations Director, key quotes No-shows cost us a chair a day across 12 clinics., pain points No-shows, Manual reminder calls, buying triggers New location opening, value realized Fewer no-shows); Clinic Group B (role Practice Manager, key quotes Rescheduling by phone takes half my morning., pain points No-shows, Rescheduling by phone, buying triggers Patients asking for online booking, value realized Online booking, Fewer no-shows).

How does ICP Interview Synthesizer work?

No sign-in. A web browser is enough, and the answer comes back in a second or two.

  1. Fill in the form above, or press Fill in an example.
  2. Press Run ICP Interview Synthesizer.
  3. Read the result on this page, then copy it and edit it before you use it.

It applies fixed rules in the ICP Intelligence code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the AI assistant connector run the same tool code, so the same input gives the same answer in both.
