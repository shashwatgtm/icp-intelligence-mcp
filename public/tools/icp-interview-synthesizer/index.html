ICP Interview Synthesizer

Extract ICP patterns from customer interviews

Give it notes from your customer interviews. Get top pain points, buying triggers and value realized, key quotes, profile refinements and a template for the next round.

Try it with an exampleUse your own details

Last updated 2 October 2026

Run ICP Interview Synthesizer

Every field is optional. You can add: Interview notes, Raw transcripts, Product category, Company.

6 parts per line, separated by |. Put several items in one part with ; between them. For example: Example Manufacturing Co | Finance Controller | slow month-end close; manual reconciliation | new CFO hire | close 5 days faster | We spent the first week of every month matching card spends by hand

Alternative: paste interview notes or transcripts. This tool does not analyze pasted text: it shows up to 500 characters back with a template to structure them as interview_notes, which it does analyze

Up to 6,000 characters in this form. For a longer document, use ICP Intelligence in Claude, which takes up to 100,000.

Optional: what you sell, used for sector notes

Optional: your company or product name, so the answer can name it

Who is ICP Interview Synthesizer not ideal for?

  • Teams looking for a list of companies to target: the tools describe and score profiles from your data but find no companies.

How do I use ICP Interview Synthesizer from Claude?

Add ICP Intelligence once (see Use it in Claude or ChatGPT), then ask in plain words. A prompt built from the tested example:

Use ICP Intelligence's ICP Interview Synthesizer tool. interview notes: Example Manufacturing Co (role Finance Controller, pain points Slow month-end close, Manual reconciliation, buying triggers New CFO hire, value realized Close 5 days faster, key quotes We spent the first week of every month matching card spends by hand); Example IT Services Co (role Head of Accounts Payable, pain points Late expense claims, Policy breaches, buying triggers Audit finding, value realized Fewer policy breaches, key quotes Half my team's week went on chasing receipts).

How does ICP Interview Synthesizer work?

No sign-in. A web browser is enough, and the answer comes back in a second or two.

  1. Fill in the form above, or press Fill in an example.
  2. Press Run ICP Interview Synthesizer.
  3. Read the result on this page, then copy it and edit it before you use it.

It applies fixed rules in the ICP Intelligence code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the AI assistant connector run the same tool code, so the same input gives the same answer in both.
