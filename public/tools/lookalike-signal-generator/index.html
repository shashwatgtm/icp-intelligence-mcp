Who is Lookalike Signal Generator not ideal for?

  • Anyone who cannot give the required inputs (Champion titles); the answer is built only from them.
  • Teams looking for a list of companies to target: the tools describe and score profiles from your data but find no companies.
  • Market sizing without your own numbers: TAM, SAM and SOM are built from the figures you enter; an ICP match rate or market share you leave out is filled with a labelled example (30% and 3%).

How do I use Lookalike Signal Generator from Claude?

Connect ICP Intelligence once (see Connect), then ask in plain words. A prompt built from the tested example:

Use ICP Intelligence's Lookalike Signal Generator tool. champion titles: ["Operations Director", "Practice Manager"]; buying triggers: ["new location opening", "high no-show rate"]; platforms: ["linkedin"].

MCP tool name: lookalike_signal_generator. REST: POST https://icp-intelligence.gtmhelix.com/api/tools/lookalike_signal_generator with this JSON body (see Docs):

{
  "input": {
    "champion_titles": [
      "Operations Director",
      "Practice Manager"
    ],
    "buying_triggers": [
      "new location opening",
      "high no-show rate"
    ],
    "platforms": [
      "linkedin"
    ]
  }
}

How does Lookalike Signal Generator work?

It applies fixed rules in the ICP Intelligence code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server call the same tool code, so the same input gives the same answer in both.
