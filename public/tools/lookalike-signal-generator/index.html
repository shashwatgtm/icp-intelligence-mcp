Lookalike Signal Generator

Generate platform-specific targeting criteria and search queries (generates criteria, not data)

Run Lookalike Signal Generator in your browser

Required: Champion titles. Fields marked optional can be left empty.

Firmographic criteria Enter a JSON object. Fields: industries (array), company_sizes (array), locations (array), funding_stages (array).

Technologies your ICP typically uses One item per line.

Job titles of your champions One item per line.

Events that trigger buying One item per line.

Platforms to generate criteria for (linkedin, google_ads, 6sense, zoominfo) One item per line.

Result

Use it from Claude or another assistant

Connect ICP Intelligence once (see Connect), then ask in plain words. A prompt built from the tested example:

Use ICP Intelligence's Lookalike Signal Generator tool. champion titles: ["Operations Director", "Practice Manager"]; buying triggers: ["new location opening", "high no-show rate"]; platforms: ["linkedin"].

MCP tool name: lookalike_signal_generator. REST: POST https://icp-intelligence.gtmhelix.com/api/tools/lookalike_signal_generator (see Docs).

How this tool works

It applies fixed rules in the ICP Intelligence code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
