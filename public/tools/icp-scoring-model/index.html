What do I need to run ICP Scoring Model?

No sign-up. A web browser is enough, and the answer comes back in a second or two.

Every field is optional. You can add: Scoring criteria, Success correlation, Product category.

  1. Fill in the form below, or press Fill in an example.
  2. Press Run ICP Scoring Model.
  3. Read the result on this page, then copy it and edit it before you use it.

How do I run ICP Scoring Model in my browser?

Fields marked optional can be left empty.

One entry per criterion. Importance is critical, important or nice_to_have. For example: [{"criterion": "Number of locations", "importance": "critical", "values": ["5 or more"]}]

🔧 Implementation Guide

In CRM (Salesforce/HubSpot)
  1. Create custom field for each criterion
  2. Create formula field for total score
  3. Create automation rules for tier assignment
  4. Create dashboard to track score distribution
Score Validation Process
  • Weekly: Review closed-won deals for scoring accuracy
  • Monthly: Adjust weights based on win/loss patterns
  • Quarterly: Full model review with sales leadership
Red Flags (review before you qualify)

Even high scores should be reviewed if:

  • [ ] No clear problem/need identified
  • [ ] Competitor locked in with multi-year contract
  • [ ] Decision maker not accessible

Who is ICP Scoring Model not ideal for?

  • Teams looking for a list of companies to target: the tools describe and score profiles from your data but find no companies.
  • Market sizing without your own numbers: TAM, SAM and SOM are built from the figures you enter; an ICP match rate or market share you leave out is filled with a labelled example (30% and 3%).

How do I use ICP Scoring Model from Claude?

Connect ICP Intelligence once (see Connect), then ask in plain words. A prompt built from the tested example:

Use ICP Intelligence's ICP Scoring Model tool. product category: clinic scheduling software; success correlation: Customers with 5+ locations and a central operations team renew most.

How does ICP Scoring Model work?

It applies fixed rules in the ICP Intelligence code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the AI assistant connector run the same tool code, so the same input gives the same answer in both.
